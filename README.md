# Koffee

universal roblox internal suite. external-tier feature kit through an internal runtime, in a UI that respects the user.

funded by [Konstant](https://github.com/lowkeymyself/HowToAccountJadeShipClaudeTryHackMe), separate product.

## load

private repo -- see [docs/loading.md](docs/loading.md) for the PAT-based loader.

## structure

- `dist/koffee.lua` -- runnable bundled script. monolithic during round 1; will split into `src/` when it outgrows a single file.

## keys

- `RightShift` -- toggle main window

## runtime

any 99% sUNC internal (Volt, Potassium, Real, Synapse Z, Cosmic). externals cannot run Koffee -- their script runners are sUNC-trash. pair with an internal.
